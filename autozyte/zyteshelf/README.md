# ZyteShelf

Inventory parent module for AutoZyte.

| Sub-module | Scope |
|------------|--------|
| **ZyteShelf** | Charter, shared models, shelf in / shelf out |
| **ZyteBin** | Bin location, aisle, pick path |
| **ZyteStock** | On-hand, reserved, low-stock |
| **ZyteLedger** | Returns, restock, job closeout, accounting tie-out |

**Not** shop order history — that lives in `shop/` warehouse.

Code lands here when CT brings over the inventory work from the other tool.
