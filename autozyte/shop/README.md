# shop/

Shop history warehouse, ShopMonkey REST ingest, trend screens, and Jake advisor UI surfaces.

- **warehouse** — SQLite history (not ZyteShelf live inventory)
- **synthetic** — Porsche 1980–2025 seed (no SMS key)
- **ingest** — paginated ShopMonkey → warehouse
- **service** — read APIs for trends and status
- **cli** — `python -m shop.cli`
